# Лабораторная работа № 10. Автокодировщик

Цель работы — обучить автокодировщики на MNIST и проверить их на задачах реконструкции, обнаружения аномалий и шумоподавления.

## Запуск

```powershell
python -m pip install -r requirements.txt
python lab10.py
```

При первом запуске Keras скачает MNIST. Все три задания выполняются последовательно.
`model.py` содержит модель и обучение, `lab10.py` — задания и графики.
Число эпох задаётся в начале `model.py`: `EPOCHS = 50`, `ANOMALY_EPOCHS = 100`.
Для быстрой проверки можно временно поставить оба значения равными 1.
Метрики выводятся в консоль, графики PNG сохраняются в `results`. JSON не создаются.

## Методика

1. **Реконструкция.** Нормализуем пиксели в диапазон [0, 1] и разворачиваем изображения в векторы по 784 значения. Обучаем сеть `784 → 128 → 64 → 32 → 64 → 128 → 784` на парах из одинаковых изображений. В скрытых слоях применяется ReLU, на выходе — sigmoid. Используем Adam, бинарную кросс-энтропию (BCE), 50 эпох и пакет из 256 изображений. Латентный слой уменьшает число признаков в 24,5 раза.
2. **Аномалии.** Обучаем новую сеть той же архитектуры 100 эпох только на цифре 0, используя среднеквадратичную ошибку (MSE). Порог равен 95-му перцентилю MSE на обучающих нулях. Для каждого тестового изображения вычисляем MSE по всем 784 пикселям и отмечаем его как аномалию при превышении порога. Цифры 1–9 считаем истинными аномалиями.
3. **Эксперименты.** Сравниваем латентные слои из 2, 32 и 128 признаков. Для шумоподавления добавляем к пикселям гауссовский шум с σ = 0,4 и обрезаем значения до [0, 1]. На вход подаём зашумлённые изображения, а ошибку считаем по чистым. Для сравнения сходимости меняем активацию всех скрытых слоёв между ReLU, tanh и ELU. Выходной sigmoid сохраняется.

Для сопоставимости фиксируем начальное состояние генераторов (`seed = 42`) и сохраняем одинаковые параметры обучения в сравниваемых опытах. Как в задании, стандартная тестовая выборка MNIST также используется для расчёта ошибки на каждой эпохе.

## Интерпретация результатов

- **Размер латентного слоя.** При двух признаках сеть вынуждена кодировать форму, наклон и толщину штрихов всего двумя числами. Близкие коды могут соответствовать изображениям с разными деталями. Тогда декодер усредняет яркость в спорных пикселях, и края штрихов выглядят размытыми. В варианте с 128 признаками соседние слои по-прежнему имеют ширину 64, что ограничивает информацию, которая проходит через сеть.
- **Аномалии.** Порог по обучающим нулям задаёт примерно 5% превышений на этих же данных. Доля ложных срабатываний на тестовых нулях может отличаться. Полнота показывает долю обнаруженных цифр 1–9, а точность — долю цифр 1–9 среди всех отмеченных изображений.
- **Шумоподавление.** Сравниваем MSE зашумлённого входа и MSE восстановленного изображения относительно одного и того же чистого оригинала. Уменьшение MSE показывает, насколько восстановленные изображения в среднем ближе к оригиналам.
- **Сходимость.** Сравниваем тестовую BCE на первой, десятой и последней эпохах. Первые две точки характеризуют раннюю динамику, последняя показывает качество после одинакового числа эпох. График также содержит ошибки на обучающей выборке.

## Результаты предыдущего полного прогона

**Задание 1. Реконструкция.** После 50 эпох тестовая BCE составила 0,083046, а MSE — 0,007146. На [графике реконструкции](results/01_reconstruction.png) показаны десять тестовых оригиналов и их восстановленные версии.

**Задание 2. Обнаружение аномалий.** После 100 эпох порог MSE составил 0,016334. Модель обнаружила 8 977 из 9 020 тестовых цифр 1–9 (полнота 99,52%). Из 980 тестовых нулей она ошибочно отметила 73 (7,45%). Точность среди отмеченных изображений составила 99,19%. [Распределение ошибок и порог](results/02_anomalies.png).

**Задание 3. Эксперименты.**

- При 2, 32 и 128 признаках тестовая MSE составила 0,038710, 0,007146 и 0,005261 соответственно. С двумя признаками ошибка примерно в 5,4 раза выше, чем с 32. Увеличение ширины с 32 до 128 дало меньший прирост качества. [Сравнение реконструкций](results/03_latent.png).
- После шумоподавления MSE относительно чистых оригиналов снизилась с 0,079671 до 0,015261, то есть на 80,85%. [Примеры шумоподавления](results/03_denoising.png).
- На 10-й эпохе наименьшая тестовая BCE была у ReLU (0,098415). К 50-й эпохе наименьшая BCE была у tanh (0,081599), затем у ReLU (0,083046) и ELU (0,083718). В этом прогоне ReLU быстрее вышла на низкую ошибку, а tanh дала чуть меньшую итоговую ошибку. [График сходимости](results/03_activations.png).
